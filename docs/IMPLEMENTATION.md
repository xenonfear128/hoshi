# Hoshi 实施与验收

目标：可部署、真实连接的 SSH/SFTP Web 工作台，账号之间不共享资源。

- [x] 注册/登录/退出、Argon2id、服务端会话、CSRF/Origin 防护、限流
- [x] PostgreSQL 持久化、版本化迁移、AES-GCM 主机/凭据加密、账号隔离
- [x] 主机 CRUD、分组搜索、密码/私钥/临时凭据、指纹确认与变化阻断
- [x] 多标签交互终端、分屏、resize、保活、断开清理、重连、搜索、多行粘贴确认
- [x] Linux CPU/内存/Swap/负载/磁盘/网卡监控，每秒采样、上下行平滑趋势、缺失数据
- [x] SFTP 路径导航、隐藏项、排序、新建/移动/删除/权限、文本编辑与冲突保护
- [x] 流式多文件上传下载、进度/速度/取消/重试、覆盖确认、全局传输中心
- [x] AI 设置：加密 BYOK、自定义 HTTPS 地址与 SSRF 防护、订阅来源、模型选择、用量
- [x] AI 命令助手：自然语言/命令前缀/解释修正/追问、单行填入不执行、主动选择上下文
- [x] AI 运维：选主机、方案、精确命令授权、流式执行、取消、结果分析、脱敏历史与关联追问
- [x] 订阅：服务端额度账本、预占/幂等结算、Stripe 托管支付/管理入口及签名账单 Webhook
- [x] 亮暗主题、独立终端主题、三分区可调整布局、细分网络图、WebGL 液态玻璃材质与故障降级、手机三视图与触屏终端按键
- [x] Docker/Caddy/Postgres 部署、备份/密钥轮换/密码重置/运维文档
- [x] 单元、协议集成、真实 SSH、浏览器、HTTPS 代理和容器运行验证

验收证据、已知协议边界和生产环境接入条件见 [VERIFICATION.md](VERIFICATION.md)。

## 明确边界

- 单应用实例；数据库实例锁禁止多实例或运行中密钥轮换。
- 普通补全与历史快捷键使用远端 Shell；不伪造任意全屏程序中的行内补全。
- 每个 AI 任务一台主机。首版所有步骤均需确认，未启用无人值守自动诊断。
- 只删除空目录；文件夹上传、打包下载和断点续传属于后续版本。
- 下载使用同源 Service Worker（现代浏览器 + 正常信任链 HTTPS），不整份缓存文件。
- 无会话断线保留，重连建立新会话；长期任务使用 tmux。
- 支付和 AI 外部服务须由部署者配置。协议与签名测试使用隔离服务，不等于真实商户或模型账户验收。

## 技术实现

React 19 / TypeScript / Vite，xterm.js、ECharts、CodeMirror、Zustand；Go 1.26.8 / chi / PostgreSQL pgx；模块化单体。首版不需要 Redis 或独立 Agent。
