# Hoshi · 星 · Stellar

## 品牌名称

| 界面语言 | 唯一展示的项目名 |
|---|---|
| 中文（zh-CN） | 星 |
| 日本語（ja） | Hoshi |
| English（en） | Stellar |

导航、登录页、首页、AI 页面与网页标题只使用当前语言对应的一个名称，不附其他语言副标题，不并列三名称。桌面和手机遵循同一规则。图标保持一致，语言切换即时更新名称与界面文案。语言选择、翻译范围和行为见 [三语界面规范](I18N.md)。

## 图形

采用用户提供的斜向星轨 icon，保留长短线的比例和方向。`design/brand/hoshi-source.jpg` 保存原图。`web/public/brand/` 提供应用图标、透明白色字形、favicon 和 Apple touch icon。字形直接从附图提取，用 CSS mask 适配亮暗主题，未重新生成或替换图案。

不拉伸图形，不叠加星形符号或渐变填色；小尺寸保持黑白对比。导航采用平面字形，收藏图标保留原图的黑色底座。

## 视觉语言

“深空、银白、微光”。以中性表面、细描边和留白组织信息，斜向光轨呼应 icon。液态玻璃继续使用 WebGL 折射，降低过亮边缘，替换原来的绿蓝背景和染色。正文、终端和文件保持高可读性。

| 色彩 | 深色 | 亮色 |
|---|---|---|
| 画布 | #0B0C10 | #F5F5F7 |
| 面板 | #131419 | #FFFFFF |
| 正文 | #EEEFF3 | #22242D |
| 次级文字 | #A3A6B3 | #666B7A |
| 品牌强调 | #D9DEF5 银紫白 | #414D79 岩紫 |

界面优先使用黑白银灰。淡紫用于交互强调；网络上下行分别使用银紫、灰蓝；在线状态和危险操作保留独立语义颜色。强调色不替代告警颜色。

标题采用中等字重，正文以 14 px、辅助文字以 12–13 px 为基准，终端保留等宽字体，默认 14 px / 1.25 行高。拉丁文字本地托管 Inter 400/500/600，中文与日文使用对应语言的系统无衬线字体栈。主机卡片以细边和轻阴影区分，不用强烈发光。手机导航只展示当前语言的项目名，功能布局沿用“终端 / 监控 / 文件”。

## 文案

- 首页：**连接每一颗星。**
- 副标题：你的主机、文件与下一步操作，在此相连。
- 登录页：连接每一颗星。专注每一步。
- AI 入口：从一句话，到下一步。
- AI 运维：让下一步，更清晰。

品牌标题可以表达“星”的意象，功能与确认必须直白：连接主机、上传文件、生成方案、确认执行、停止任务。错误说明实际原因和可采取的动作。不会将主机叫作“星体”或将危险执行包装为隐喻。

## 兼容性与验证

前端包名与用户界面更名为 Hoshi。既有 Go 模块、命令目录、Cookie/下载协议等内部 `remoter` 标识保留，避免品牌更新使现有部署或数据失效。原 `bak/v0.0.1` 保持不变。
