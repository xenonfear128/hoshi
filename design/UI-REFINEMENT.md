# UI 阅读与布局改进

基于 [审查清单](UI-AUDIT-2026-09-10.md) 的实施记录。保留星轨品牌、三语单一名称、深浅主题和左监控 / SSH / 下方文件工作区。

| 审查项 | 已落实的变化 | 实现 / 验证证据 |
|---|---|---|
| 1 字体 | 同源 Inter 400/500/600；中日分别配置系统字体栈；正文 14 px、辅助 12–13 px，取消 8–10 px 数据说明 | public/fonts 的文件及许可证；浏览器实际渲染为 Inter-SemiBold，见 contrast JSON |
| 2 编辑器 | 桌面 1200 px 上限、84vh；手机近全屏；文件名两行上限、目录单独显示、保留路径两端并可复制完整值 | Files.tsx / file-editor-modal；四屏宽三语截图与标题/编辑区尺寸断言 |
| 3 手机 AI | 运维记录折叠、目标与地址分层、需求输入在示例之前；有方案时缩小页标题 | AIPage.tsx；首屏生成按钮可达断言、12 条任务/长输出检查 |

| 6 工作区 | 监控 270 px（中屏 250 px）且保留收起；文件文字 12–13 px；终端默认 14 px、1.25 行高、可调 | Workspace.tsx；真实终端输入/屏幕输出与语言切换实例保留 |

## 验收范围

- 三语 × 深浅主题 × 390 / 768 / 1280 / 1512 px，覆盖主页、主机表单、BYOK/订阅、AI 输入、工作台、文件浏览/编辑和命令助手。手机额外检查滚动后的网络区。
- 登录与注册：三语 × 深浅主题 × 390 / 1512 px。
- 交互：长文件名/目录、12 条历史任务和长输出、紧凑列表、嵌套弹窗、Escape 取消、焦点恢复、路径移动/权限请求、终端搜索。
- 390×480 模拟软键盘后的可视区域，756×500 模拟 1512×1000 在 200% 缩放下的 CSS 布局尺寸。不是实际系统软键盘或浏览器缩放 UI 的硬件验收。
- 对比度通过截图实际背景像素计算，测量时关闭文字过渡并临时隐藏目标文字以避免采到抗锯齿前景。抽样覆盖页面副标题、备注、地址、页脚、导航、玻璃设置说明、网络统计。最低抽样值深色 7.45:1、浅色 5.12:1，均超过 4.5:1；不宣称所有远端 ANSI 文本或任意外部输出都满足该值。
- 真实 SSH/SFTP 使用专用 PostgreSQL 库和本机 OpenSSH；手机使用 Chromium 触屏仿真。后端业务逻辑未修改，生产注册限流保留。

## 回归结果

最终生产构建下，61 项不同的浏览器回归均通过（分批执行，菜单外点击的测试位置修正后补跑通过）：24 项布局矩阵、7 项玻璃/响应式、7 项三语状态切换、19 项交互/字体/对比度/登录/空状态、3 项真实桌面 SSH/SFTP/账号隔离、1 项手机真实 SSH/SFTP。10 项前端单元测试、TypeScript/Vite 构建及 Prettier 通过。

构建仍提示终端与监控分包较大；本轮未调整后端业务逻辑、计费或部署配置，也未改动既有备份。
