# 界面规范

亮主题采用冷白与翡翠绿：画布 #F3F6F8、面板 #FFFFFF、抬升区域 #EAF0F3、正文 #17252E、次级文字 #627581、分隔线 #DCE5EA、强调色 #087F6D。深色使用石墨底与薄荷绿。

连接视图固定为左侧监控、主要 SSH 终端、下方可调整文件面板。磁盘默认根挂载点，提供全部挂载点选择；长名称截断并保留完整提示。网卡优先常规以太网或无线接口，仍可选择虚拟网卡。

网络每秒采集累计计数并计算实际时间差速率，上下行独立显示，使用轻度单调平滑曲线和浅色面积。提供 1/5/15 分钟窗口、当前/平均/峰值、网卡累计流量。平滑仅用于绘制，数值不做均值滤波；采样缺失断开曲线，不伪造零值。

液态玻璃已接入用户指定 liquid-glass-webgl 项目的距离场与透镜算法，覆盖导航、卡片、弹出面板、监控与 AI 助手。材质折射应用装饰背景；终端正文、文件列表保留稳定实底。支持 WebGL 故障回退与减少动态效果偏好。实现与测试说明见 ../docs/LIQUID-GLASS.md。

手机端使用底部主导航与“终端 / 监控 / 文件”视图切换，提供触屏终端快捷键、文件卡片和响应式弹窗。
